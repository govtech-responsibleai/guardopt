idle

Every grey dot is a policy someone could have shipped. The bloom is slowed down for drama — the actual evaluation time is measured and shown above, honestly. Guardrail prices are our measured per-call costs for a real three-tier judge fleet (1× / 21× / 52×); score distributions are synthetic, because your traffic is the thing worth measuring. Policies whose precision is undefined (blocked nothing) are excluded, not scored 0 — same rule as the real optimiser.

five minutes

Scores in. Frontier out.

No framework to adopt, no service to run. If your guardrail scores are already in a spreadsheet, you don't even need Python.

# pip install git+https://github.com/govtech-responsibleai/guardopt
from guardopt import ScoreMatrix, optimise

matrix = ScoreMatrix.from_csv("scores.csv", guardrails)
result = optimise(matrix)

for rec in result.recommendations:   # Minimal · Balanced · Strict
    print(rec.explanation.limitations)  # honesty first, always

result.recommendations[1].policy.to_file("policy.json")
🎯 One search, every shape. Flat policies and banded cascades compete in one space — the optimiser discovers whether routing wins on your data, rather than assuming it.
🧾 Numbers you can defend. Wilson intervals on every rate, a holdout split that catches the winner's curse, bootstrap stability on every pick, and a distribution-free bound on the deployed miss rate.
⚡ A runtime that matches. The policy file is enforced by a fail-closed router proven to decide exactly as measured — plus shadow mode, drift monitoring, and exporters for LiteLLM and friends.
